資産クラス 総資産に含める ダッシュボードに表示

「ダッシュボードに表示」にチェックした資産クラスが、ダッシュボード上部で切り替えられるようになります。何も選ばない場合は、保有がある資産クラスが自動で表示されます。

オンにすると保有一覧の預金・現金が「A銀行 他N件」の1行に合算されます。銀行ごとの内訳は行のツールチップ・銘柄詳細・クラス別/口座別ページで確認できます。

価格ソース連携（未設定の銘柄）

投資信託協会のデータベースから銘柄を検索して紐づけると、基準価額の履歴とチャートが利用できます。年金（iDeCo・企業型DC）の投信も連携でき、評価額から口数を逆算して日々の基準価額で自動評価されるようになります。
