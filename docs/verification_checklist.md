- [ ] 「既定に戻す」で初期構成に戻る

- [ ] 「総資産に含める」チップでクラスを外すと総額が即座に変わる
- [ ] 設定ページの資産クラス表で「ダッシュボードに表示」をONにすると、
      保有が無いクラス（暗号資産・不動産など）もダッシュボードにチップが出る
- [ ] 何もチェックしない場合は、保有があるクラスが自動でチップになる
- [ ] 総資産から外しているクラスのチップは常に残る（戻せなくならない）
- [ ] 広い画面でドーナツ2枚（クラス構成・タグ別構成）が横に並ぶ

## Myポートフォリオ / タグ
- [ ] タグ名を一覧の中で直接書き換えられる（作り直し不要）
- [ ] タグ色をパレットまたはピッカーで変更でき、ドーナツ・チップに即反映される
- [ ] 色を変えても名前・銘柄への割当は保持される
- [ ] 既存タグと同名にしようとするとエラーになり、元の名前に戻る
- [ ] タグを削除すると銘柄への割当とポートフォリオ条件からも外れる
- [ ] 銘柄にタグの配分率（%）を入力すると即保存され、残り%表示が更新される
- [ ] 合計100%超の入力は保存されず「超過」表示になる
- [ ] 配分が100%未満の銘柄がある場合、上部に警告帯（件数・未配分額・銘柄名）が出る
- [ ] 未配分の銘柄は行が黄色く強調され、リストの先頭（未配分額の大きい順）に並ぶ
- [ ] 「未配分のみ」チップで未配分の銘柄だけに絞り込める
- [ ] 全銘柄を100%配分すると警告帯が消える
- [ ] タグ別サマリーのドーナツと表の合計が総資産と一致する（未配分は「未分類」）
- [ ] タグ別サマリーの行（またはドーナツのスライス）をクリックすると、そのタグの
      構成銘柄・計上率・計上額が表示され、合計がサマリーの金額と一致する
- [ ] タグ詳細では「タグ別」カードが隠れる（自明なため）
- [ ] 「未分類」をクリックすると未配分の割当リストに移動する
- [ ] ポートフォリオを作成し、対象タグを選ぶと按分計上される
      （例: 国内株式のみ選ぶと、オルカンは日本株の配分ぶんだけ入る）
- [ ] ポートフォリオ詳細でタグ別・通貨別・クラス別・口座別・構成銘柄が表示される
- [ ] 構成銘柄の「計上率」が按分どおりに出る（全額計上の銘柄は100%）

## 取引履歴の取込（証券会社CSV / Excel / 貼り付け）
書式判定は「ヒューリスティックが当たること」より「外したときに気づけること」を確認する。

- [ ] 「取込」ページに「資産内訳PDF」「取引履歴」のタブが出て、切り替わる
- [ ] 口座を空のまま解析すると、口座を選ぶよう警告が出る
- [ ] 実際の取引履歴CSVを取り込み、**列の対応**が正しく判定される
      （約定日 / 銘柄 / 取引区分 / 数量 / 単価 / 約定代金 / 受渡金額 / 手数料 / 口座区分）
- [ ] 前文（口座番号・出力日時）と末尾の合計行が取込対象から外れている
- [ ] 検算（数量×単価＝約定代金）の合格数がプレビューに出る
- [ ] 投資信託のファイルで「投信（1万口あたりの基準価額）」と判定される
- [ ] 列の対応を手で変えて「この対応で再解析」すると、その対応で読み直される
- [ ] 未照合の銘柄が出た場合、候補が★付きで先頭に提示され、選ぶとその行が「新規」に戻る
- [ ] 確定後、同じファイルをもう一度上げると 409（取込済み）になる
- [ ] **期間が重なる別ファイル**を取り込むと、重複ぶんが「取込済み」として除外され二重計上しない
- [ ] Excel(.xlsx) と、証券会社の画面からコピーした表の貼り付けが読める
- [ ] 旧Excel(.xls) を上げると「.xlsx で保存し直してください」と案内が出る

### 取得日・取得原価
